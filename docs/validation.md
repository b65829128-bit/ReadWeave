## alpha.13：停止后保留对话、重建读取授权（2026-10-17）

alpha.12 基本闭环通过后，用户报告“停止后似乎进新会话了”，并明确选择“保留对话上下文，继续追问”。旧实现为隔离停止时序而结束整个话题，本轮修改该体验；这条反馈不作为已经观察到串话、授权越界或上游停止失败的证据。

“停止回答”立即保存不完整回答与工具状态，撤销旧授权；下一问等待撤销完成，再用最初的书籍、选区、位置与范围创建新任务。新授权与后端专用会话各有新标识，本地对话 ID、历史内容、旧引用保持。正常追问不重放历史；停止后替换会话只携带有长度限制的最近可见消息和所引原文，不携带旧读取句柄、未完成工具协议或思考过程。换书、改范围 / 设置、切换或停用后端仍另开安全历史。

桥接插件升至 0.1.1，AstrBot 继续固定 v4.27.4。停止中的话题拒绝再启动；停止应答后另读后端活动状态，10 秒内无法确认则失败。排队、执行中和异步密钥核对期间的工具返回会重新检查状态。关闭在远程停止 / 删除失败时仍释放名额；话题过期与断线提供明确错误，不自动重发资料。实现与限制见 [统一任务入口](task-runtime.md) 和 [插件更新步骤](../integrations/astrbot/astrbot_plugin_readweave/README.md)。

- **半页偏移**：Android 原生选区手柄拖动没有 pointer 事件，却会直接滚动阅读引擎的 overflow-hidden 容器。alpha.10 第一页物理起点由 `760` 变成 `892.57` CSS px，页宽仍为 `760`，CFI 不变。新增 `setSelectionLocked`，选文期间恢复未经授权的物理偏移；真正的导航、重排和动画通过引擎自身滚动函数更新锁。补丁同步进入复现脚本和 VENDOR.md。
- **键盘**：旧 WebView 138 的键盘弹出后 innerHeight / visualViewport 仍为约 `1292`，输入框底部约 `1191`，实际已被键盘覆盖。新增受版本控制的 `src-tauri/android/MainActivity.kt`，由准备脚本复制到生成项目，声明 adjustResize 并在原生容器处理系统栏、缺口和 IME 区域，向 WebView 继续传递已归零的区域，避免新版重复避让。实现参考 [Android WebView 窗口区域说明](https://developer.android.com/develop/ui/views/layout/webapps/understand-window-insets) 和 [软键盘处理指南](https://developer.android.com/develop/ui/views/layout/sw-keyboard)。
- **布局稳定**：底部 / 侧边面板按窗口宽度、触摸方式及物理屏幕方向决定。竖屏键盘使窗口变成宽大于高时仍保持底部面板；低可用高度下扩大面板并让输入表单保持可见。

## alpha.10 触摸选区、竖屏面板与引用显示

用户在 Android 日常阅读中反馈：选区手柄拖到翻页区仍会翻页；竖屏打开阅读伙伴后正文重排，选文提问可能丢失；回答结束后偶尔仍显示 `[[citation_…]]`。

已确认并处理的路径：

- foliate-js 自带触摸滑页及 700ms 延迟选区翻页，与宿主的触摸判断同时运行。新增可复现的 `host-controls-input` 补丁，由 ReaderAdapter 统一识别手势；一次手势开始时或过程中出现选文，即使原生选区暂时折叠、触摸取消或释放到页外，也不会变成翻页。正常横滑只翻一页。

- 原引用正则只接受紧贴括号的 `cite_` 加字母数字。现在兼容外围空白、转义括号、单独行内代码包装及编号中的下划线 / 连字符；错误前缀、缩写和未签发编号显示“引用未核验”，不猜测原文。已有引文正文核对继续生效。内置 Harness 每次带上具体的有效编号格式，适用于已有保存的模型设置。没有取得这次偶发现象的完整模型原始回答，不能断言已覆盖所有服务输出变体。

- 动作包启停在数据库写入前被受控输入回弹，改为及时更新并在失败时回退。
- 原生内容策略缺少同源连接许可，导致打包后本地示例书加载失败。已增加同源项，并在浏览器回归中启用相同策略。
- 存储 ID 校验未容纳动作包的点分命名，已与包格式统一。
- 取消后旧任务仍可能更新另一个阅读页面的显示，现先撤销任务并切断界面关联。
- 已知 citationId 不能证明模型引号内的文字是真实引文；增加直接引文和块引用的不匹配提示。
- 相同和交叠选区反复写入高亮，现按范围切换并移除既有交叠高亮，保留独立笔记。
- 整段选区的元素边界序列化为折叠 CFI，导致覆盖层不可见；现在先转换为实际文本节点边界，并通过包含内联节点和 emoji 的往返测试。
- 桌面目录的关闭按钮和开关未生效；现在所有宽度均按开关显示面板，全屏控件叠加唤醒。
- 阅读引擎外侧边距收不到 iframe 内点击；由 ReaderAdapter 同时处理正文与边距。鼠标正文保留双击选词，触摸拖动 / 长按与翻页分开。
- 原思考流被忽略，工具调用只有通用状态文字，追问只保存最后答案；已增加独立展示、可展开工具记录与完整协议消息回传。
- SSE 的 `finish_reason: length` 过去会当成成功，现在提示预算不足，并记录为未完成。
