# 大书性能记录

日期：2026-10-15。版本：`0.1.0-alpha.6`。

用户反馈《资治通鉴（切块版）》导入、打开会停顿一二十秒，翻页和选文正常。本轮集中处理进入阅读前的开销，保持清理、内容策略、书籍哈希、原生登记和授权检查。

## 原因与改动

- 66,022 段正文在生成 CFI 时反复枚举同一批兄弟节点。CPU 采样中约 14 秒消耗在这些重复遍历。增加仅用于单份静态文档的 WeakMap，复用节点索引；交互定位保留原调用方式。补丁、复现脚本与 VENDOR 说明同步更新。
- 导入后曾销毁解析结果，再读原文件重新解析。现在直接使用这份已校验结果打开；回到书架后，仅保留当前一本已加载的书供重开，取最新保存的位置。切换书籍会释放旧书，关闭进程后不保留这份内存缓存。
- 按约 8 毫秒预算分批让出界面线程；取消打开、返回书架或关闭应用会终止待处理的 Worker / 提取任务，避免完成后突然打开已离开的书。打开失败也不会被“导入成功”提示覆盖。
- Windows 原书读写使用 Tauri 二进制 IPC，避免把大文件展开为数千万个 JSON 数字。写入仍在 Rust 检查尺寸、内容哈希和路径，使用独立临时文件；Android 保留原 JSON 请求路径，设备验收仍未执行。
- 已有数据库先解析到文件的实际位置，再打开 SQLite，使主文件、WAL、SHM 与迁移备份位于同一物理目录。现场主文件本身通过完整性检查，混合重定向视图却会误读另一位置的日志。没有替换数据库或清空书库。
- 原生 SQLite 从 3.51.1 更新到 3.53.2，rusqlite 精确固定为 0.40.2，锁文件和许可同步更新。新版包含 SQLite 已公布的 [WAL-reset 修复](https://sqlite.org/wal.html#walreset)；该已知缺陷不被当作现场目录问题的已证实原因。

## 同一本书的测量

本机 Microsoft Edge 隔离上下文，原文件 20.59 MiB、289 节、66,022 段。生产页面加载原生端相同的内容策略；只记录耗时与采样函数，没有上传原书或提交正文资料。

| 操作                               | alpha.5 |          alpha.6 首轮测量 |
| ---------------------------------- | ------: | ------------------------: |
| 单次正文提取与定位生成（源码模块） | 19.0 秒 |                    2.9 秒 |
| 导入并打开（生产浏览器）           | 38.9 秒 |                    4.6 秒 |
| 返回书架后重开（生产浏览器）       | 21.0 秒 |                   0.10 秒 |
| 单次提取的最长界面任务             | 18.2 秒 | 未观察到超过 50 ms 的任务 |

浏览器数据用于对照算法和流程，不能当作 Windows EXE 或 Android 的端到端计时。单次测量不是性能上限；首次加载还包括解压、安全清理、原生登记和排版。

Windows 实际窗口另行核验：首次打开《资治通鉴》约 5.1 秒出现阅读界面，正文翻页正常；返回书架后重开约 0.3 秒，恢复到刚才的简介页。计时包含电脑操作工具调用 / 观察开销，采用约 250 ms 的状态轮询，不代表精密基准。

最终包关闭再启动后恢复简介页通过。数据库完整性检查正常，原有 9 条记录保留；仅本次阅读的书籍位置更新，其他记录的内容摘要未变。

## 原文与定位保持一致

新提取结果仍为 8,204,363 个 UTF-16 正文单位。按原生字段顺序计算全部段落与 CFI 的指纹，与 alpha.5 已登记结果完全一致：

```text
c9b678ba738881a7dc94cc90425bd7f053b548393585c8fa67e7cb51a2594b2c
```

《万历十五年》仍为 32 节、1,938 段、249,368 个 UTF-16 单位。两本原文件分别通过原生登记 / SQLite 重开测试；生产浏览器导入、显示正文、翻页、重开通过，外部请求为 0。

新增回归覆盖缓存与原 CFI 一致性、Windows 字节传输 / Android 请求兼容、并发原书保存、数据库目录别名。51,000 段的浏览器流程验证导入只创建一个解析 Worker，同次重开不新建 Worker，刷新后重新校验并恢复位置；另覆盖取消停留中的导入、后续打开仍正常。

完整检查与 Windows 交付文件见 [验证记录](validation.md)。Android、原生文件选择框中的本轮重新导入，以及复杂大书长期内存 / 性能仍不在本次完成的设备验收范围内。
