# DeepSeek 适配记录

核对日期：2026-10-14；2026-10-18 复核到当前版本。自 `0.1.0-alpha.2` 起适用，当前为 `0.1.0-alpha.14`。

参考：[首次调用 API](https://api-docs.deepseek.com/zh-cn/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)、[Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。文档的模型建议可能继续变化，服务地址和模型名称保留可编辑入口。

## 已实现

- DeepSeek 服务类型独立于普通兼容服务。新配置建议 `deepseek-flash`；提示另一个当前模型 `deepseek-v4-pro`。保留用户旧配置名称。
- `thinking.type` 为 `enabled / disabled`；开启时 `reasoning_effort` 为 `low / high / max`，关闭时为 `none`。不发送无效的温度或惩罚设置，也不强制思考模式下不支持的工具选择方式。
- 单次 `max_tokens` 在界面可选 8K / 16K / 32K / 64K，默认 32K，思考与回答共用预算。这是应用选择的预算，不冒充服务默认值。
- 单独累积并展示 SSE `reasoning_content`；正文仍来自 `content`。思考过程以纯文本呈现，不执行 HTML 或加载远程资源。
- 带工具时，完整保存当前问题各子回合的 assistant 消息（包含思考、正文和工具调用）及 tool 结果。连续追问回传保留回合的完整协议消息，不仅发送最终答案。历史最多保留最近六组问答；按完整问答裁剪，超出 512 KiB 请求上限时提示新话题，不截断单个思考或工具交换。
- 工具执行记录显示准备 / 执行 / 成功 / 失败 / 取消，以及工具名称、原始参数和返回结果。读取权限仍由冻结的书籍版本、范围和六次预算决定；模型参数不能切换书籍。
- 浏览器和原生请求超时统一为 10 分钟，传输上限 16 MiB；单子回合思考上限 128,000 字符、单问题合计 256,000 字符，正文 64,000 字符。超时、额度 / 参数错误、输出预算截断会显示未完成状态；用户可以随时取消。
- JSON 备份包含思考、工具记录与协议历史；旧设置 / 备份补齐缺省配置。浏览器预览的密钥只在本次运行内存中；Windows / Android 原生端自 alpha.8 起使用平台安全存储，密钥不进入这些数据。

## 验证边界

单元测试和本机 SSE 协议服务覆盖思考参数、增量展示、工具执行与错误、跨工具子回合及追问的思考回传、取消、JSON 备份兼容和密钥不持久化。生产浏览器测试加载与原生一致的内容安全策略。

本次没有提供真实 DeepSeek 密钥，未向商业模型发送书籍，也没有真实服务响应或计费证据。以上证明实现和协议流程，不等于真实 DeepSeek、Android 或外部 Harness 已验收。真实服务仍需补充长时间思考、限流、断网、取消和多轮工具的实测记录。alpha.14 的读取额度反馈与异常后续问由统一任务入口处理，不改变本页列出的模型参数或请求格式。
