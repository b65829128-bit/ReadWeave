# 开发计划

当前：P0 技术验证中，含可试用的阅读和内置问答原型。下列清单对应原方案，不把接口声明或模拟测试当成外部能力验收。

## 已落地的基础

- [x] Git 初始化、原方案归档、项目入口、锁文件和许可。
- [x] React / Tauri 原生容器、Rust SQLite、书籍文件和流式网络请求。
- [x] 固定 foliate-js、EPUB 导入和安全清理、Worker 展开校验。
- [x] 书架、目录、分页、主题排版、位置恢复、基本标注。
- [x] 冻结上下文、受限搜索和片段读取、来源引用、流式问答与取消。
- [x] 声明式动作包完整生命周期、JSON 备份与 Markdown 导出。

## 下一个里程碑：补齐 P0 证据

1. 准备实际自用的历史书与技术教材，核对格式、DRM、扫描页与图片公式占比。原创示例不能替代这些样本。
2. 安装并确认 Android SDK、NDK、JDK 和 Rust Android 目标。构建真机 APK，确认 WebView 最低版本；连续 50 次选区，记录误翻页、旋转、键盘和面板变化。
3. 将正文索引、读取授权和引用签发迁入 Rust；绑定设备、书籍版本、快照与调用身份。再实现 rmcp 工具服务，复用这套授权。
4. 固定 Hermes / ACP 版本，实现最小 Connector，验证一次真实任务的提问、双向工具、追问、澄清与取消。不能只验证单向聊天。
5. 配置两个真实模型服务，验证兼容接口、流式增量、工具参数、超时、限流和取消行为。
6. 验证 Windows / Android 安全凭据库，再决定是否启用凭据持久化。

## 随后的阅读与问答完善

- 完整复合 Locator：资源路径、spine、CFI、exact/prefix/suffix 和规范化偏移映射；失效与多候选的明确交互。
- SQLite FTS5、中文分词、短词受限扫描以及可解释的索引完成状态。
- 更完整的嵌套目录、EPUB 图片 / SVG / CSS 的受限支持和大书性能。
- 问答历史的正文预算、过期任务重开、撤销范围后安全历史重建。
- 原生文件导入 / 导出体验、空间不足、应用关闭、文件损坏、备份迁移和失败恢复。
- 自用连续一周的轻量观察，不以提问次数或聊天时长作为成功指标。

## v0.1 发布前

必须完成原方案第 12 节的双平台安装、阅读、数据、模型、外部 Harness、插件和安全验收。当前 Windows 开发包仅用于试用，没有签名、自动更新或正式发布承诺。

可执行插件、插件市场、PDF / OCR、云同步、知识图谱、代码运行和自动课程继续后置。
