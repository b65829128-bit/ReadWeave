2026-10-16：alpha.10 后续真机反馈暴露了浏览器回归未覆盖的路径。alpha.11 在 OPD2513 / Android 16 / WebView 138 上确认：慢滑被半秒门槛误拦截，系统选区手柄可直接滚动容器而不发送 pointer 事件，旧 WebView 键盘弹出后可用区域未更新。已修正手势判定、锁定选区期间的物理页偏移，并通过可复现的 Android Activity 模板处理键盘与系统栏区域；面板按物理屏幕方向布局，键盘不触发布局切换。真机已验证六次不同速度的往返滑动、左右原生选区手柄、取消选文后翻页及横竖屏真实键盘；正式 APK 已更新，范围见 [验证记录](validation.md)。

2026-10-17：用户补充 AstrBot 由 uv 安装，确认版本 v4.27.4；按安装包版本记录，不要求存在 Git 工作区。用户建立 SSH 转发后，本工作区通过真实 API 验证密钥鉴权、流式问答、追问、新会话和停止。发现开放对话的自定义用户名与通用停止路由的 API Key 身份不同，身份不一致时 HTTP 200 仍返回应用错误；使用同一密钥身份的会话后，输出中和首字前停止均通过。尚未实现 ReadWeave 外部适配器、可信 MCP 回调、书内引用或 Android / 公网 HTTPS，具体边界见接入计划和验证记录。

## 当前建议的开发顺序

日常使用继续补齐更细的导入进度与更多实际 EPUB 样本。平台安全凭据与首个 APK 的实际证据已经记录；浏览器预览和新的 AstrBot 密钥继续只留内存。统一任务入口与 AstrBot 基本闭环已通过本机测试及用户实际使用验证，下一步优先补稳定性和授权边界验收。alpha.11 连续选区和其他真实模型验收继续补齐；影响阅读、数据或授权的问题优先处理。

1. **原生书内服务：首阶段已落地。** 正文块、书籍与变换版本、冻结授权、读取预算和引用定位已经迁入 Rust / SQLite，并接上当前内置问答。数据库升级保留旧记录；重启不恢复旧授权。正文提取仍经可信宿主与 ReaderAdapter，检索仍明确为受限扫描；完整复合定位和可重建全文索引继续完善。
2. **统一任务与扩展入口：内置路径已落地。** TaskRuntime 接管准备、预览、执行、取消和保存；适配器注册表实际路由内置后端，切换 / 停用撤销旧任务。执行 runId 与宿主 sessionRef 分开，迟到事件不更新新书或新会话；同会话保存有序，旧备份兼容。外部后端会话握手、重连与交互协议继续单独实现。
3. **AstrBot v4.27.4 内置 Agent。** 版本确认、SSH API 预检、本机适配器 / 桥接插件 / 原生 MCP 已完成；真实 Bot、工具调用和原文引用已由用户人工确认。优先在 alpha.14 / 插件 0.1.1 复测工具额度反馈、异常后可见历史与模型上下文，再验证换书 / 改范围和断线失败。公网 HTTPS 与 Android 链路分别验收。

不影响阅读、数据或授权的交互细节纳入后续待办，在相关模块迭代时集中完善；误翻页、数据丢失、定位错误和授权越界仍优先修复。每一步交付可运行行为与相应验证，保留现有阅读入口，不以接口声明代替实现。
